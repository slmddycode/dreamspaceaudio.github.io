Privacy policy

DreamSpace Rotate · Effective 7 November 2026

Who uses this app

DreamSpace Rotate is a private tool used only by the owner of the DreamSpaceAudio YouTube channel, to manage that channel's own live broadcasts. It is not offered to the public.

What it accesses

With the channel owner's permission, the app uses the YouTube Data API to:

  • read the channel's name, live stream settings and live broadcasts
  • create, start and end the channel's live broadcasts
  • set the thumbnail on those broadcasts

It does not access viewers' data, comments, messages, email or any other Google data.

What it stores

The app stores its sign-in token and its settings only on the channel owner's private server. Nothing is stored anywhere else.

Sharing

No data is sold, shared or transferred to anyone. DreamSpace Rotate's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The channel owner can remove the app's access at any time at myaccount.google.com/permissions.

Contact

Questions can be sent through the DreamSpaceAudio YouTube channel.
